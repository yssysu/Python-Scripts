* [X] *osm_to_shp.py:* 批量的将 `osm`文件转化成 `shp`文件，只需要设置输出路径，该脚本即可自动获取窗口目录下所有 `osm`图层。其他格式的文件尚未测试。

* [X] *移除外部磁盘.py*: 在 macOS 上检测并安全弹出外部磁盘（包括物理驱动器和磁盘映像）。

> 该脚本专门为 macOS 设计，用于管理外部存储设备以及软件安装包（dmg）
> 功能包括：自动检测新连接或移除的外部磁盘（物理驱动器如 U 盘、移动硬盘，以及挂载的磁盘映像 .dmg）。
> 显示当前连接的外部磁盘列表，包含名称、大小和设备路径。
> 提供交互式菜单，允许用户：
>   - 通过输入数字选择并弹出单个磁盘。
>   - 输入 'e' 一键弹出所有检测到的外部磁盘并退出程序。
>   - 输入 'r' 刷新磁盘列表。
>   - 输入 'd' 查看详细的调试信息。
>   - 输入 'q' 退出程序。
> 当最后一个外部磁盘被单独弹出后，程序会自动退出。
> 注意：弹出磁盘映像（.dmg）可能因文件正在使用而失败。脚本会尝试报告弹出失败的原因。
> 无需额外安装库，依赖 macOS 内建的 `diskutil` 命令。可能需要管理员权限（使用 `sudo` 运行）来确保 `diskutil` 命令正常执行。
